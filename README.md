# Enterprise Linux Administration & Automation

A hands-on Linux administration project designed to simulate a small enterprise environment using **RHEL, Ubuntu, and Windows Server**.

The project focuses on building, securing, managing, monitoring, and automating Linux infrastructure.

## 🚀 Project Highlights

* Active Directory and DNS integration
* RHEL and Ubuntu domain integration
* Apache and Nginx web servers
* Linux users, groups, permissions, and ACLs
* SSH, sudo, and systemd administration
* firewalld, UFW, and SELinux
* Bash automation and service monitoring
* System and web log analysis
* Backup and restore
* Cron scheduling
* Linux troubleshooting

## 🏗️ Environment

| System         | Role                                          |
| -------------- | --------------------------------------------- |
| Windows Server | Active Directory & DNS                        |
| RHEL           | Apache, Security, Administration & Automation |
| Ubuntu         | Nginx, Administration & Web Services          |
